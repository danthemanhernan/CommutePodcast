## Suggested lab

Add a `cooling_anomaly_detected` event to the DataCenterDigitalTwin project with:

- stable incident and asset identifiers;
- event and ingestion timestamps;
- schema version and data-quality metadata;
- contributing measurements and baselines;
- confidence and evidence references.

Test duplicate delivery, late delivery, and a missing evidence source. Keep agent output advisory until deterministic authorization and safety boundaries exist.
